02 입찰 도구 — 크롬/엣지 확장 프로그램
설치: 크롬 주소창에 chrome://extensions → 우측 위 "개발자 모드" 켜기 → "압축해제된 확장 프로그램을 로드합니다" → 이 폴더 선택.
사용: 나라장터(g2b.go.kr)·KISTI(kisti.re.kr)·국방전자조달(d2b.go.kr) 공고 화면을 열면 오른쪽 아래에 분석 패널이 뜹니다. 다른 사이트는 도구 모음의 확장 아이콘을 누르면 그 화면을 분석합니다.
"도구에서 열기"를 누르면 전체 화면 도구(app.html)가 열리며 읽은 값이 자동 입력됩니다. 데이터는 이 PC 밖으로 나가지 않습니다.
